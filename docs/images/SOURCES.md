# Promotional image sources

These screenshots were captured from the existing [Nudge Sites design prototype](https://nudge-reminders-studio.jasonwang224.chatgpt.site) on November 7, 2026. They show illustrative sample reminders, not a user's native reminder database.

| File | View |
| --- | --- |

| `nudge-editor.jpg` | New reminder, typed time, and Nag Me controls |

Images are cropped to the phone preview without changing the depicted interface. They are design references, not native iOS screenshots. The README describes the current native app; prototype wording and controls may differ. In particular, iOS controls actual notification appearance, and the native app has a finite notification queue.

The README's app icon comes from `Nudge/Assets.xcassets/AppIcon.appiconset/Nudge.png`.
